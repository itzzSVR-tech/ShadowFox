## <a name="introduction">🤖 Introduction</a>

Welcome to the ****Royal Challengers Bangalore**** project! Our goal is to develop an immersive, visually stunning, and highly responsive website that brings the cricket to the digital world. This project serves as a comprehensive showcase for a modern RCB experience, prominently featuring dedicated sections for the team, players, and matches.

Built from the ground up utilizing semantic **React**, modern **TailwindCSS**, and **Framer Motion** (powered by the lightning-fast **Vite** build tool), the website emphasizes best practices in frontend web development without relying on heavy UI frameworks. We achieve a premium, polished user experience by seamlessly incorporating smooth, subtle scroll animations and fluid transitions that bring the interface to life.

## <a name="tech-stack">⚙️ Tech Stack</a>

- React
- Tailwind CSS
- Framer Motion
- Vite
